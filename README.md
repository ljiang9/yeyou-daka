# 夜游打卡模拟器 yeyou-daka

一晚 5 小时（18:00–23:00），在虚构的"夜游小城"里规划打卡路线：
8 个夜游点各有耗时、花费、快乐值、体力消耗，体力归零会被强制送回酒店。
随机事件可能让你快乐暴击，也可能让你在夜市排队一小时，
或者被沉浸式 NPC 拉上台演路人甲——社死但快乐。

## 热点来源声明

致敬 2026 国庆夜游经济热点："沉浸式演出""烟花秀""夜游"标签景区搜索量
同比增长超五成，多地景区夜游延时开放。本游戏的业态灵感（沉浸式街区、
光影秀、灯会、夜市、游船、剧本杀、观星、深夜书店）来自真实夜游经济形态，
但**所有地点名称、事件均为虚构**，如有雷同纯属巧合。
本游戏为娱乐向模拟，不构成任何旅游消费建议。

## 玩法

- 交互模式：`python3 -m yeyou_daka`（需要终端），每一步从可选打卡点里选编号
- 自动演示：`python3 -m yeyou_daka --auto --games 10 --seed 42`
  （AI 贪心规划：每一步选单位时间快乐值最高的去得起的点）
- `--verbose`：打印每一局的整晚战报

结算：评分 = 打卡数 × 总快乐值

| 评分 | 称号 |
| ---- | ---- |
| ≥ 1800 | 夜游之王 |
| ≥ 1200 | 特种兵夜猫 |
| < 1200 | 早睡早起养生派 |

随机事件（每次打卡 35% 概率触发其一）：

| 事件 | 效果 |
| ---- | ---- |
| 烟花秀临时加场 | 本次快乐值 ×1.5 |
| 夜市排队一小时 | 额外耗时 1 小时 |
| 被 NPC 拉上台 | 快乐 +40、额外耗时 0.5 小时、社死值 +1 |

## 已知局限（诚实版）

- 数值（耗时/花费/快乐值/体力）为拍脑袋设定，平衡性未经大规模仿真调优
- AI 只是"单位时间快乐值最高"的贪心规则，不会考虑事件概率和组合策略
- 事件纯随机触发，无真正的"人流/热度"模型；文案为固定池，多玩几局会眼熟
- 纯文本界面，无图形、无存档、无联机；预算/体力为简化模型，不代表真实消费
